# JS Clock — v2

A clock app in plain HTML, CSS and JavaScript. Version 2 of [js-clock](https://github.com/asmaa21102/js-clock).

**Try it:** https://asmaa21102.github.io/live/js-clock/index.html

## Features

- Analog and digital clock, 12- or 24-hour format
- World clocks with time differences
- Stopwatch with laps (fastest and slowest marked)
- Timer with a progress ring and a sound alert
- Arabic, English and Turkish; light and dark mode

## Run

No build step — open `index.html` in a browser.
